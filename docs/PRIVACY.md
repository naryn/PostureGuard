# 隐私与数据说明

## 1. 一句话版本

摄像头画面只在本机内存中用于姿态推理，处理完立即丢弃；应用没有网络权限，不保存图片或视频，数据库里只有校准数值、时长统计和事件时间/指标。

## 2. 数据流

```
CameraX 预览 ──► 屏幕显示
CameraX 分析帧 ──► Bitmap ──► 本机 MediaPipe 模型 ──► 33 个关键点
                                                   │
                                         计算角度/时长/事件
                                                   │
                                             Room 本地数据库
```

- 分析帧使用 `STRATEGY_KEEP_ONLY_LATEST`，始终只保留最新一帧，不排无限队列。
- 关键点只在内存中参与当帧计算，不落盘、不缓存历史序列。
- 没有 `INTERNET` 权限，应用无法向任何服务器发送数据（包括崩溃日志、统计和广告 SDK）。
- 没有第三方分析、广告或崩溃上报 SDK。

## 3. 权限

| 权限 | 用途 | 何时申请 |
| --- | --- | --- |
| `CAMERA` | 获取侧视画面进行本地姿态推理 | 首次进入摆放/校准/监测页 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_CAMERA` | 监测期间显示持续通知，让用户知道相机在使用 | 开始监测时 |
| `POST_NOTIFICATIONS` | 显示前台服务通知（Android 13+） | 首次进入监测页 |
| `VIBRATE` | 姿态提醒（可在设置关闭） | 无运行时弹窗 |

拒绝相机权限时应用不会崩溃，只会显示权限说明与「打开系统设置」。

## 4. 本机保存的内容

Room 数据库（应用私有目录，其他应用不可读）：

- **校准基准**：三个角度的中位数与 MAD、躯干尺度、质量、朝向、侧别、模型版本。用于计算相对变化量。
- **监测会话**：开始/结束时间、总时长、有效/正常/各类异常/低质量/暂停时长、使用的校准 ID、是否正常结束。
- **每日/每小时聚合**：按会话拆分，用于统计报告。
- **异常事件**：类型、开始/结束时间、持续时长、严重度、峰值偏差。

不保存：

- 图片、视频、屏幕截图；
- 原始关键点序列或人脸特征；
- 姓名、账号、位置、通讯录等个人身份信息；
- 任何可回放到具体画面的数据。

## 5. 数据保留与删除

- 数据默认一直保留在本机，直到用户主动删除或卸载应用。
- 设置 → 数据与隐私：
  - 「删除全部历史统计」：删除会话、每日/每小时聚合和异常事件；
  - 「删除校准数据」：删除个人校准基准，下次监测前需重新校准。
- 卸载应用会删除数据库与设置。
- `android:allowBackup="false"`，应用数据不会进入系统云备份。

## 6. 前台与后台

- 相机绑定在 Compose 页面生命周期上：离开监测页、按返回或锁屏时释放相机并暂停会话。
- 前台服务只用于展示「正在本地监测」通知和提供停止入口，不持有相机，也不会在页面不可见时继续推理。
- 应用不做后台保活，不申请忽略电池优化，不使用 `WAKE_LOCK` 常驻。

## 8. 儿童与敏感场景

应用不面向儿童设计，也不用于医疗监护。请勿在浴室、更衣室等隐私场景使用；画面虽然不上传，但预览会显示在屏幕上，请注意周围环境。

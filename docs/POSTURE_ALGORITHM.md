# 姿态算法说明

本文描述从关键点到提醒的完整计算链。所有数值均为**工程默认值**，不是医学标准，也不构成诊断依据。

## 1. 输入

MediaPipe Pose Landmarker Lite（float16）在 `LIVE_STREAM` 模式下输出 33 个归一化关键点，每个点包含 `x, y, z, visibility, presence`。应用只使用侧视所需的点：

- 鼻子 `NOSE`
- 选定侧的耳朵、肩、髋（`LEFT/RIGHT_EAR`、`LEFT/RIGHT_SHOULDER`、`LEFT/RIGHT_HIP`）

`x, y` 为归一化坐标（0–1，左上角为原点，y 向下）。

## 2. 纵横比校正

归一化坐标的 x、y 使用不同尺度，直接用会因画面比例产生几何失真。计算前先把 x 乘以画面宽高比：

```text
aspect = imageWidth / imageHeight
sx = shoulder.x * aspect
hx = hip.x * aspect
ex = ear.x * aspect
nx = nose.x * aspect
```

下文所有 `x` 均为乘过 `aspect` 的值。

## 3. 面向方向

用户可选择「面向画面右侧」或「面向画面左侧」。定义符号：

```text
f = +1  (FACING_RIGHT)
f = -1  (FACING_LEFT)
```

所有前后方向的分量都乘以 `f`，因此同一套阈值适用于两种朝向，摄像头在身体哪一侧不影响状态含义。

## 4. 三个指标

### 4.1 躯干尺度

```text
torsoScale = hypot(sx - hx, shoulder.y - hip.y)
```

用于把像素距离换算成「躯干长度」单位，使指标与坐姿远近无关。有效范围 `0.02 ≤ torsoScale ≤ 1.5`。

### 4.2 头部前移（forwardOffset）

耳朵相对肩在水平方向的前出量，按躯干尺度归一化：

```text
forwardOffset = f * (ex - sx) / torsoScale
```

- 0 表示耳朵与肩在同一竖直线上；
- 正值表示耳朵位于肩的前方（头前移）；
- 除以 torsoScale 后不同距离下的数值可比。

### 4.3 低头角（headAngleDeg）

鼻子相对耳朵的方向，以水平线为 0°：

```text
headAngleDeg = atan2(nose.y - ear.y, f * (nx - ex)) * 180/π
```

- 0° 表示鼻、耳近似水平；
- 正值表示鼻子低于耳朵（低头）；
- 负值表示抬头。

### 4.4 躯干前倾角（torsoAngleDeg）

肩相对髋的方向，以竖直向上为 0°：

```text
torsoAngleDeg = atan2(f * (sx - hx), -(shoulder.y - hip.y)) * 180/π
```

- 0° 表示肩在髋正上方；
- 正值表示肩在髋前方（躯干前倾）；
- 负值表示后仰。

### 4.5 相对变化量

监测时不直接比较绝对值，而是比较相对个人校准基准的变化：

```text
Δforward = forwardOffset - baseline.forwardOffsetMedian
ΔheadDown = wrap180(headAngleDeg - baseline.headAngleMedianDeg)
ΔtorsoLean = wrap180(torsoAngleDeg - baseline.torsoAngleMedianDeg)
```

`wrap180` 把角度差映射到 [-180°, 180°)，避免 ±180° 边界跳变。

## 5. 关键点质量门控

只有满足下列条件的帧才参与状态机计时和统计：

1. 鼻子、选定侧耳/肩/髋全部存在且置信度 ≥ 0.5；
2. 四点都在画面内（允许 2% 边缘容差）；
3. `torsoScale` 在 0.02–1.5；
4. 耳朵高于髋（排除倒置/异常人体）；
5. 左右侧选择稳定：最近 15 帧中，若已满 8 帧且左右切换比例 > 35%，判为 `SIDE_UNSTABLE`。

任一条件不满足，该帧记为低质量：`metricsValid = false`，不累计任何姿态时长。

## 6. 个人校准

### 6.1 采集窗口

- 总时长 15 秒，前 2 秒为预热，不计入样本；
- 只接受质量有效、且侧别与当前选择一致的帧；
- 最少 40 个有效样本，有效比例 ≥ 60%；
- 否则返回「有效样本不足」并提示重试。

### 6.2 稳健统计

对每个指标：

1. 计算中位数 `median`；
2. 以 `3 × MAD` 为界裁剪离群值（`Geometry.trimOutliers`）；
3. 对裁剪后的样本重新计算中位数与 MAD。

MAD（median absolute deviation）比标准差更抗离群帧。

### 6.3 稳定性验收

若裁剪后仍满足以下任一条件，校准失败（姿势在采集期间变化过大）：

| 指标 | 允许的最大 MAD |
| --- | --- |
| 头部前移 | 0.12 |
| 低头角 | 15° |
| 躯干角 | 12° |

校准结果保存为 `CalibrationProfile`：三个中位数、三个 MAD、躯干尺度中位数、质量中位数、有效比例、朝向、侧别、模型版本。

## 7. 有效阈值

### 7.1 灵敏度

| 预设 | 系数 |
| --- | --- |
| 宽松 | 1.30 |
| 均衡 | 1.00 |
| 灵敏 | 0.78 |

### 7.2 噪声下限

个人校准的 MAD 用于抬高最小阈值，防止把校准噪声当成异常：

```text
噪声底 = 3 × MAD + 固定下限
固定下限：头部前移 0.04，角度 4°
轻度阈值 = max(默认轻度 × 灵敏度系数, 噪声底)
明显阈值 = max(默认明显 × 灵敏度系数, 轻度阈值 × 1.8)
```

默认值：

| 指标 | 轻度 | 明显 |
| --- | --- | --- |
| 头部前移（躯干单位） | 0.10 | 0.22 |
| 低头（相对基准） | 10° | 22° |
| 躯干前倾（相对基准） | 8° | 18° |

## 8. 滤波

三个指标分别经过帧率无关的指数移动平均：

```text
α_eff = 1 - (1 - α)^(dt / 100ms)
value = α_eff × sample + (1 - α_eff) × previous
```

默认 `α = 0.3`，`dt` 限制在 1–1000 ms。角度使用最短路径（±180° 环绕）更新。作用：

- 抑制单帧关键点抖动；
- 不同帧率（5/10/15 FPS）下平滑程度一致；
- 只对质量有效的帧更新，低质量帧不污染滤波状态。

## 9. 时间制状态机

每个条件有独立计时器。只有质量有效的帧才推进时间。

| 参数 | 默认值 |
| --- | --- |
| 轻度确认时长 | 8 秒（可在设置中改为 5/8/12 秒） |
| 明显确认时长 | 3 秒 |
| 恢复确认时长 | 4 秒 |
| 低质量宽限 | 1.2 秒 |
| 最大帧间隔 | 600 ms |

### 9.1 条件优先级

当多个条件同时成立：

1. **埋头**：低头与前移都至少为轻度，取两者中较低的严重度；
2. 低头；
3. 头部前移；
4. 躯干前倾。

### 9.2 确认

- 计时未达到对应阈值：状态为「注意…」，不触发提醒；
- 计时达到阈值：状态为「…」，进入可提醒状态；
- 明显比轻度更快确认。

### 9.3 恢复

条件不再成立后，计时器进入恢复期：

- 4 秒内重新成立，保留已累计时长；
- 持续 4 秒正常，计时清零；
- 恢复期内仍显示上一次异常状态，并带「正在恢复」标记，避免状态闪烁。

### 9.4 无人 / 低质量

- 检测不到人：显示「未检测到人体」，所有计时冻结；连续 3 秒（且不小于恢复时长）后清零各条件；
- 质量不足但检测到人：1.2 秒宽限内保持上一状态，超时后显示「检测质量不足」；
- 两种情况都**不**累计正常或异常时长。

## 10. 提醒

- 只有已确认的异常状态才会生成提醒；
- 同类条件有冷却时间（默认 120 秒，可设 1/2/5 分钟）；
- 回到「姿态自然」后清空各条件的冷却记录；
- 提醒通道取「设置开关」与「提醒计划器」的交集；
- 声音：`ToneGenerator` 双短音；语音：系统中文 TTS；振动：`Vibrator`（API 31+ 使用 `VibratorManager`）。

## 11. 手机位置变化

以校准时的躯干尺度为基准：

```text
ratio = 当前 torsoScale / 校准 torsoScaleMedian
```

- `ratio < 0.72`（明显变远/变小）或 `ratio > 1.38`（明显变近/变大）持续 8 秒；
- 帧间隔超过 2 秒则重新计时；
- 只显示「手机位置可能变化，建议重新校准」，不改变任何分类结果；
- 重新校准后重置基准。

## 12. 统计口径

每帧按互斥类别累计（最长 2 秒一跳，跨小时自动拆分）：

| 类别 | 条件 |
| --- | --- |
| 正常 | 质量有效且状态为「姿态自然」 |
| 头部前倾 / 低头 / 埋头 / 躯干前倾 | 质量有效且当前状态属于对应异常（含「注意…」阶段） |
| 低质量 | 检测到人但质量无效，或未检测到人 |
| 暂停 | 用户主动暂停或相机中断 |

「正常」只包含质量有效的时段；低质量、暂停与离开画面单独展示，绝不并入正常。异常事件只在进入已确认异常时创建，记录开始/结束时间、时长、严重度与峰值 delta。

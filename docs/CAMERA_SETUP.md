# 手机摆放指南

侧视坐姿检测对机位比模型更敏感。同一套算法在正确机位下更稳定；机位不当时，质量门控会显示「检测质量不足」而不是给出错误结论。

## 1. 推荐机位

```
        ┌──────────── 墙面/书架 ────────────┐
        │                                   │
        │      ● 耳朵                        │
        │       \                            │
        │        ● 肩   ← 手机（后摄朝人）    │
        │        │         约 0.8–1.5 米     │
        │        ◌ 髋（可选）                 │
        │       /                            │
        │      █ 椅面 / 桌面                  │
        └───────────────────────────────────┘
```

- **侧面**：手机放在身体左侧或右侧，镜头光轴尽量垂直于矢状面，不要从斜前方 45° 拍。
- **高度**：镜头大致与肩同高，略低于眼；避免俯拍或仰拍造成前倾量偏差。
- **距离**：0.8–1.5 米，保证头和肩完整入画。髋部入画时可额外判断驼背/弯腰（肩髋角度），拍不到也不影响头肩前移和低头检测。
- **稳定**：使用支架/书堆固定，避免放在会晃动的桌面边缘。
- **不遮挡**：镜头与眼睛、鼻子、嘴、耳朵和肩之间不要有显示器、绿植、杯子和手臂。

## 2. 摄像头与朝向

「摆放手机」页和设置页都可在**后置 / 前置摄像头**之间切换：前置预览会镜像显示，分析使用未镜像帧，骨架叠加会自动对齐。默认推荐后置；切换摄像头会改变画面投影与尺度，必须重新校准。

同一页面还可选择你**面向画面的方向**：

- 手机在右侧、你面朝左 → 面向画面左侧；
- 手机在左侧、你面朝右 → 面向画面右侧。

如果校准时左右侧关键点反复跳动（`SIDE_UNSTABLE`），通常说明机位接近正面或侧面特征不明显，先调整机位，再切换朝向重试。

## 3. 光线与背景

- 避免强逆光（窗户在身后），否则人体轮廓发黑、关键点置信度低。
- 避免侧后方强光造成半边脸过曝。
- 背景尽量简洁，人体轮廓与背景有对比；深色衣服配浅色墙最容易稳定。
- 夜间请开主灯，不要只靠屏幕光。

## 4. 使用流程

1. 固定手机，打开「摆放手机」页，授予相机权限。
2. 检查四项实时提示：检测到人体、头肩在画面内、眼睛和嘴部可见、左右侧关键点稳定。
3. 选择朝向，坐下保持自然坐姿。
4. 进入「个人校准」，前 2 秒预热，之后保持约 15 秒不动。
5. 校准成功后回首页开始监测，全程保持监测页在前台。

## 5. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 一直显示「未检测到人体」 | 人不在画面、逆光、遮挡、距离过远 | 调整机位，让人体占画面更大，补光 |
| 「关键点置信度不足」 | 逆光、宽松衣物、半边身体出画 | 换到顺光位置，露出耳朵与肩线，收窄构图 |
| 「人体过小或距离过远」 | 手机太远 | 移到 0.8–1.5 米内 |
| 「头或肩超出画面」 | 构图偏上/偏下 | 调整镜头高度，确保头和肩入画 |
| 肩髋角度显示「—」 | 未拍到髋部 | 属正常现象，头肩前倾和低头仍正常判断 |
| 低头变化显示「—」 | 眼睛或嘴部不可见、被遮挡或置信度低 | 调整机位/光照，让面部侧面完整入画；低头判断会恢复 |
| 「左右侧关键点不稳定」 | 机位偏正面或侧别频繁切换 | 更接近正侧方；在设置中切换朝向并重新校准 |
| 前置画面左右相反 | 前置预览按镜像显示 | 属正常现象，分析使用未镜像帧 |
| 切换摄像头后状态异常 | 投影与尺度变化，旧基准不匹配 | 重新校准后再监测 |
| 「手机位置可能变化」 | 手机被移动、镜头被碰 | 结束本次监测，重新校准 |
| 校准失败「姿势波动较大」 | 采集期间说话、转头、调整坐姿 | 保持自然坐姿、少动，重新校准 |
| 校准失败「有效样本不足」 | 光线差、遮挡、频繁离开画面 | 改善机位与光照后重试 |
| 监测中画面卡顿 | 设备性能不足、帧率设太高 | 设置中改为「省电 5 FPS」 |

## 6. 边界与限制

- 只支持**侧视**：正面、背面、明显斜角下的前倾量不可靠。
- 只观察上半身：头和肩必须同时可见；髋部可选，拍不到时不做驼背/弯腰判断，头肩前倾与低头仍可用。
- 低头判断需要眼睛与嘴部可见；眼睛缺失时头肩偏移改用鼻子与耳朵，不影响前倾判断。
- 不识别具体疾病、不评估椎间盘或肌骨状态。
- 手机移动后必须重新校准；应用只会提示，不会自动修正基准。
- 指标几何定义升级后，旧版本校准会失效并提示重新校准。
- 强逆光、多人入画、宠物遮挡都可能导致质量下降；此时统计会归入低质量而非正常。
- 相机与推理只在监测/校准/摆放页前台运行，锁屏或切换应用会暂停。
